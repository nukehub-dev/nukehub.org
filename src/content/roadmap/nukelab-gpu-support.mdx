GPU support shipped in the NukeLab v2 cycle: plan-based GPU passthrough for workspace containers (Podman CDI / Docker DeviceRequests) with quota accounting, whole-GPU exclusive reservations with race-safe booking, GPU metrics in the monitoring stack, and a CUDA environment image (`docs/operations/GPU-SETUP.md`).
