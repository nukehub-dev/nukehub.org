NukeLab v2.1.0 (released 2026-08-22) makes deployments reproducible: git tags drive the release, CI builds and pushes tagged backend, frontend, and environment images to GHCR, production hosts pull pinned images instead of rebuilding from source, `nukelabctl db-migrate` snapshots the database before migrating, and a startup guard refuses to boot an old image against a newer schema.
